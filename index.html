            privacy_tip Privacy Policy & Data Safeguards

            Transparent disclosures regarding local SQLite storage, AI evaluation endpoints, and your rights to inspect and purge data.

            Transparent Local Storage

            storage 1. Local SQLite Audit Storage

            When you submit a text message, suspicious URL, or audio recording for analysis, SCAM BREAKER records the audit record locally in the SQLite database (scans table) running on this machine. This enables your local Scan History view, risk filtering, and PDF threat certificate generation.

            No Cloud Sync: We do not operate external telemetry tracking servers. Your historical scan records remain exclusively inside your local SQLite database file.

            psychology 2. AI Analysis & External API Transmission

            To provide explainable threat intelligence, text queries and audio transcripts are processed through the Google Gemini API using official enterprise API keys. The text payload is transmitted securely via HTTPS TLS 1.3 to Google's inference servers for real-time classification.

            Training Safeguards: Under Google API terms for enterprise inference endpoints, user prompts submitted via API are not utilized to train public foundational AI models.

            cookie_off 3. Zero Commercial Ad Trackers & Zero Tracking Cookies

            SCAM BREAKER does NOT load Google Analytics, Facebook Pixel, advertising beacons, or commercial tracker scripts. The application operates solely with local in-memory session variables and browser localStorage solely to preserve active scan state across page reloads.

            delete_sweep 4. Media Ephemerality Policy

            Uploaded screenshot images and recorded voice clips are held in ephemeral RAM/temporary buffer files exclusively for OCR text extraction and speech-to-text recognition. Once text is extracted, temporary audio and image files are immediately unlinked from the server filesystem.

            cleaning_services 5. Full User Data Sovereignty & Instant Data Purge

            You retain complete control over your scan history. You can permanently wipe all stored SQLite records at any time with a single click.
